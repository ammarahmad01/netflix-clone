# Netflix Clone

A Netflix-inspired streaming UI, containerized with Docker and served via Nginx.

## Run with Docker

docker pull ammar0990/netflix:latest
docker run -d -p 80:80 --name netflix ammar0990/netflix:latest

Then open: http://localhost

## Docker Hub
https://hub.docker.com/r/ammar0990/netflix

## Tech Stack
- Nginx
- Docker
